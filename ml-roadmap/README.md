# ML from Scratch — Interactive Course

A one-stop-shop website for learning machine learning from scratch: full written
lessons (not link lists), textbook-quality math via KaTeX, runnable PyTorch/NumPy
code snippets, interactive playgrounds, knowledge-check quizzes, and progress
tracking saved to `localStorage`.

## Curriculum

| Module | Topic |
| --- | --- |
| 0 | Linear & Logistic Regression, loss functions, gradient descent |
| 1 | Support Vector Machines — margins, hinge loss, the kernel trick |
| 2 | PyTorch fundamentals — tensors, autograd, DataLoaders, the training loop |
| 3 | Multi-Layer Perceptrons & backpropagation |
| 4 | Optimization (Momentum, RMSProp, Adam) & regularization (Dropout, BatchNorm…) |
| 5 | Convolutional Neural Networks & learned representations |
| 6 | Transformers — self-attention, multi-head attention, positional encoding |
| ★ | Advanced challenges & neural-network debugging |

Interactive playgrounds: gradient descent stepper, activation functions, SVM
margin explorer, optimizer race, convolution-by-hand, and attention visualizer.

## Stack

Next.js (App Router) · Tailwind CSS v4 · react-katex · recharts · lucide-react ·
react-syntax-highlighter
