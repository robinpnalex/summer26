built using numpy

## implementation
- sigmoid activation

- backprop
- gradient descent

# stuff I learnt
### binary cross entropy/log loss
    The more likely an event is to occur the less information it requires to convey that event.
    Information can be calculated as
        h(x) = -log(P(x))
    where P(x) is the probability of the event
